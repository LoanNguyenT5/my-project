# My Project

A web application built with **.NET 10** and **Blazor**.

## Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download)

## Getting Started

Restore dependencies and run the app:

```bash
dotnet restore
dotnet run
```

Then open the URL shown in the console (e.g. `https://localhost:5001`) in your browser.

## Build

```bash
dotnet build
```

## Test

```bash
dotnet test
```
